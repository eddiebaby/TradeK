## Test Engineering Excellence
- **Unit Tests**: 70% of test pyramid, fast execution (< 100ms), isolated and focused
- **Integration Tests**: 20% of pyramid, realistic scenarios (< 5s), component interaction
- **End-to-End Tests**: 10% of pyramid, full workflows (< 30s), critical path coverage
- **Property Testing**: Hypothesis-driven testing with 1000+ examples
- **Mutation Testing**: Minimum 80% score, target 90% for business logic
- **Contract Testing**: API contract validation and consumer-driven tests
- **Chaos Testing**: Failure injection and resilience validation

## Quality Standards
- Test Coverage: Minimum 90%, Target 95%
- Mutation Score: Minimum 80%, Target 90%
- Code Complexity: Maximum 10 cyclomatic complexity
- Method Length: Maximum 20 lines per method
- Security Vulnerabilities: Zero tolerance
- Performance: < 100ms response time, > 1000 rps throughput

## Implementation Workflow
1. **Red Phase**: Write failing tests that define expected behavior
2. **Green Phase**: Implement minimal code to make tests pass
3. **Refactor Phase**: Improve code quality while maintaining tests
4. **Quality Gates**: Automated validation of coverage, mutation, security
5. **Monitoring Setup**: Observability and alerting configuration
6. **Deployment Pipeline**: Automated deployment with rollback capability
