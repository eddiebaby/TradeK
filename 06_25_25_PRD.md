# PRDPlan.md - Trade Knowledge Technical Implementation

## Overview

This document defines the technical implementation for Trade Knowledge MVP using the FastAPI Full-Stack Template as the foundation. The system provides AI-powered financial analysis through a web interface, RESTful API, and Discord bot, with pay-per-call monetization.

## Core Architecture Decisions

### Base Stack (from FastAPI Template)

The FastAPI full-stack template provides a solid foundation that we'll extend for financial analysis capabilities. We'll maintain the template's structure while adding domain-specific services.

**What we keep from the template:**
- FastAPI backend with async support
- PostgreSQL with SQLAlchemy ORM
- Alembic for database migrations
- JWT authentication with secure password hashing
- Pydantic for data validation
- Docker Compose for development
- Pre-commit hooks and code quality tools
- Backend testing structure with pytest
- Frontend with React/TypeScript (if using full-stack variant)

**What we add:**
- TimescaleDB extension for time-series data
- Redis for caching and rate limiting
- Celery with RabbitMQ for background tasks
- WebSocket support for real-time data
- Stripe integration for payments
- Discord bot service
- AI/ML model serving infrastructure

```python
# app/api/api_v1/endpoints/analysis.py
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session
from app import crud, models, schemas
from app.api import deps
from app.core.celery_app import celery_app

router = APIRouter()

@router.post("/ticker", response_model=schemas.AnalysisResponse)
async def analyze_ticker(
    *,
    db: Session = Depends(deps.get_db),
    current_user: models.User = Depends(deps.get_current_active_user),
    ticker_request: schemas.TickerAnalysisRequest,
) -> Any:
    """
    Analyze a single ticker with AI-powered insights.
    Costs 1 credit per analysis.
    """
    # Check credits
    if current_user.credits < 1:
        raise HTTPException(
            status_code=402,
            detail="Insufficient credits. Please purchase more credits."
        )
    
    # Create analysis record
    analysis = crud.analysis.create(
        db=db,
        obj_in=schemas.AnalysisCreate(
            user_id=current_user.id,
            query_type="ticker",
            query_params=ticker_request.dict()
        )
    )
    
    # Queue async analysis
    task = celery_app.send_task(
        "app.worker.analyze_ticker",
        args=[analysis.id, ticker_request.dict()]
    )
    
    # Deduct credit
    current_user.credits -= 1
    db.add(current_user)
    db.commit()
    
    # Return immediate response with task ID
    return {
        "analysis_id": analysis.id,
        "task_id": task.id,
        "status": "processing",
        "credits_remaining": current_user.credits
    }

@router.get("/status/{analysis_id}", response_model=schemas.AnalysisStatus)
async def get_analysis_status(
    *,
    db: Session = Depends(deps.get_db),
    current_user: models.User = Depends(deps.get_current_active_user),
    analysis_id: str,
) -> Any:
    """Check status of an analysis request."""
    analysis = crud.analysis.get(db=db, id=analysis_id)
    if not analysis or analysis.user_id != current_user.id:
        raise HTTPException(status_code=404, detail="Analysis not found")
    
    return analysis
```

```python
# app/api/api_v1/endpoints/payment.py
import stripe
from app.core.config import settings

stripe.api_key = settings.STRIPE_SECRET_KEY

@router.post("/create-payment-intent")
async def create_payment_intent(
    *,
    db: Session = Depends(deps.get_db),
    current_user: models.User = Depends(deps.get_current_active_user),
    payment_request: schemas.PaymentRequest,
) -> Any:
    """
    Create a Stripe payment intent for purchasing credits.
    """
    # Credit packages
    packages = {
        "starter": {"credits": 10, "price_cents": 999},  # $9.99
        "pro": {"credits": 50, "price_cents": 3999},    # $39.99
        "enterprise": {"credits": 200, "price_cents": 14999}  # $149.99
    }
    
    package = packages.get(payment_request.package)
    if not package:
        raise HTTPException(status_code=400, detail="Invalid package")
    
    # Create Stripe customer if needed
    if not current_user.stripe_customer_id:
        customer = stripe.Customer.create(
            email=current_user.email,
            metadata={"user_id": str(current_user.id)}
        )
        current_user.stripe_customer_id = customer.id
        db.add(current_user)
        db.commit()
    
    # Create payment intent
    intent = stripe.PaymentIntent.create(
        amount=package["price_cents"],
        currency="usd",
        customer=current_user.stripe_customer_id,
        metadata={
            "user_id": str(current_user.id),
            "credits": package["credits"],
            "package": payment_request.package
        }
    )
    
    # Record transaction
    transaction = crud.transaction.create(
        db=db,
        obj_in=schemas.TransactionCreate(
            user_id=current_user.id,
            stripe_payment_intent_id=intent.id,
            amount_cents=package["price_cents"],
            credits_purchased=package["credits"],
            status="pending"
        )
    )
    
    return {
        "client_secret": intent.client_secret,
        "transaction_id": transaction.id
    }
```

```python
from app.core.security import decode_access_token

class ConnectionManager:
    def __init__(self):
        self.active_connections: Dict[str, WebSocket] = {}
    
    async def connect(self, websocket: WebSocket, user_id: str):
        await websocket.accept()
        self.active_connections[user_id] = websocket
    
    def disconnect(self, user_id: str):
        del self.active_connections[user_id]
    
    async def send_personal_message(self, message: dict, user_id: str):
        if user_id in self.active_connections:
            await self.active_connections[user_id].send_json(message)

manager = ConnectionManager()

@router.websocket("/ws/{token}")
async def websocket_endpoint(websocket: WebSocket, token: str):
    try:
        # Authenticate via token
        payload = decode_access_token(token)
        user_id = payload.get("sub")
        
        await manager.connect(websocket, user_id)
        
        while True:
            # Receive and process messages
            data = await websocket.receive_json()
            
            if data["type"] == "subscribe":
                # Subscribe to real-time updates
                await subscribe_to_symbols(user_id, data["symbols"])
            
            elif data["type"] == "analysis_status":
                # Send analysis updates
                analysis = await get_analysis_status(data["analysis_id"])
                await websocket.send_json({
                    "type": "analysis_update",
                    "data": analysis
                })
                
    except WebSocketDisconnect:
        manager.disconnect(user_id)
```

```python
# app/services/analysis_service.py
from typing import Dict, Any
import asyncio
from app.ml.models import load_models
from app.services.market_data_service import MarketDataService
from app.services.feature_engineering import FeatureEngineer

class AnalysisService:
    def __init__(self):
        self.models = load_models()
        self.market_data = MarketDataService()
        self.feature_engineer = FeatureEngineer()
        
    async def analyze_ticker(self, symbol: str, params: Dict[str, Any]) -> Dict[str, Any]:
        """
        Comprehensive ticker analysis combining multiple data sources and AI models.
        """
        # Parallel data fetching
        tasks = [
            self.market_data.get_price_history(symbol),
            self.market_data.get_fundamentals(symbol),
            self.market_data.get_news_sentiment(symbol),
            self.market_data.get_options_flow(symbol)
        ]
        
        price_data, fundamentals, sentiment, options = await asyncio.gather(*tasks)
        
        # Feature engineering
        features = self.feature_engineer.create_features({
            "price": price_data,
            "fundamentals": fundamentals,
            "sentiment": sentiment,
            "options": options
        })
        
        # Model predictions
        technical_signals = self.models["technical"].predict(features["technical"])
        fundamental_score = self.models["fundamental"].predict(features["fundamental"])
        sentiment_score = self.models["sentiment"].predict(features["sentiment"])
        
        # Ensemble prediction
        ensemble_features = {
            "technical": technical_signals,
            "fundamental": fundamental_score,
            "sentiment": sentiment_score,
            "market_regime": await self._detect_market_regime()
        }
        
        final_prediction = self.models["ensemble"].predict(ensemble_features)
        
        # Generate structured response
        return self._format_analysis_response(
            symbol=symbol,
            prediction=final_prediction,
            features=features,
            confidence=self._calculate_confidence(ensemble_features)
        )
```

```python
# app/ml/model_manager.py
import joblib
from pathlib import Path
from app.core.config import settings

class ModelManager:
    """Manages loading and versioning of ML models."""
    
    def __init__(self):
        self.model_dir = Path(settings.MODEL_DIR)
        self.models = {}
        self.load_models()
    
    def load_models(self):
        """Load all required models with fallback to defaults."""
        model_configs = {
            "technical": "technical_analysis_v1.pkl",
            "fundamental": "fundamental_analysis_v1.pkl",
            "sentiment": "sentiment_analysis_v1.pkl",
            "ensemble": "ensemble_v1.pkl"
        }
        
        for name, filename in model_configs.items():
            model_path = self.model_dir / filename
            if model_path.exists():
                self.models[name] = joblib.load(model_path)
            else:
                # Load default simple model
                self.models[name] = self._create_default_model(name)
    
    def predict(self, model_name: str, features: Any) -> Any:
        """Make prediction with specified model."""
        if model_name not in self.models:
            raise ValueError(f"Model {model_name} not loaded")
        
        return self.models[model_name].predict(features)
```

```python
# app/core/cache.py
import redis
import json
from typing import Optional, Any
from app.core.config import settings

class CacheManager:
    def __init__(self):
        self.redis_client = redis.from_url(
            settings.REDIS_URL,
            decode_responses=True
        )
        
    async def get_or_set(
        self,
        key: str,
        func,
        ttl: int = 300,
        force_refresh: bool = False
    ) -> Any:
        """Get from cache or compute and cache result."""
        if not force_refresh:
            cached = self.redis_client.get(key)
            if cached:
                return json.loads(cached)
        
        # Compute value
        value = await func()
        
        # Cache result
        self.redis_client.setex(
            key,
            ttl,
            json.dumps(value, default=str)
        )
        
        return value
    
    def invalidate_pattern(self, pattern: str):
        """Invalidate all keys matching pattern."""
        for key in self.redis_client.scan_iter(match=pattern):
            self.redis_client.delete(key)

# Usage in endpoints
cache = CacheManager()

@router.get("/market/quote/{symbol}")
async def get_quote(
    symbol: str,
    current_user: models.User = Depends(deps.get_current_active_user)
):
    return await cache.get_or_set(
        key=f"quote:{symbol}",
        func=lambda: market_service.get_quote(symbol),
```

```python
# app/core/rate_limit.py
from fastapi import HTTPException
from app.core.cache import cache_manager

class RateLimiter:
    def __init__(self, requests_per_minute: int = 60):
        self.requests_per_minute = requests_per_minute
        self.redis = cache_manager.redis_client
        
    async def check_rate_limit(self, user_id: str, endpoint: str):
        """Check if user has exceeded rate limit."""
        key = f"rate_limit:{user_id}:{endpoint}"
        
        # Increment counter
        current = self.redis.incr(key)
        
        # Set expiry on first request
        if current == 1:
            self.redis.expire(key, 60)
        
        # Check limit
        if current > self.requests_per_minute:
            raise HTTPException(
                status_code=429,
                detail="Rate limit exceeded. Please try again later."
            )
        
        return current

# Usage in dependencies
async def rate_limit_check(
    current_user: models.User = Depends(deps.get_current_active_user),
    endpoint: str = Depends(lambda request: request.url.path)
):
    limiter = RateLimiter()
    await limiter.check_rate_limit(str(current_user.id), endpoint)
```

```python
class OptimizedCRUD:
    @staticmethod
    async def get_user_with_recent_analyses(
        db: Session,
        user_id: str,

    ):

            select(User)

                    defer(Analysis.response)  # Don't load heavy JSON
                )
            )
            .where(User.id == user_id)

        user = result.scalar_one_or_none()
        
        if user:
            # Sort analyses in Python (more efficient than subquery)
            user.analyses.sort(
                key=lambda x: x.created_at,
                reverse=True
            )
            user.analyses = user.analyses[:limit]
        
        return user
    
    @staticmethod
    async def get_popular_symbols(
        db: Session,
        timeframe: timedelta = timedelta(days=1)

        cutoff = datetime.utcnow() - timeframe

                    Analysis.query_params, 'symbol'
                ).label('symbol'),
                func.count(Analysis.id).label('count')
            )
            .where(Analysis.created_at > cutoff)
            .group_by('symbol')
            .order_by(func.count(Analysis.id).desc())
            .limit(10)
        )
        
        result = await db.execute(query)
```

### Async Processing

```python
# app/services/async_helpers.py
import asyncio
from typing import List, Dict, Any
from functools import lru_cache

class AsyncBatcher:
    """Batch multiple requests to external APIs."""
    
    def __init__(self, batch_size: int = 10, wait_time: float = 0.1):
        self.batch_size = batch_size
        self.wait_time = wait_time
        self.pending_requests = []
        self.results = {}
        
    async def add_request(self, key: str, coro):
        """Add request to batch."""
        future = asyncio.Future()
        self.pending_requests.append((key, coro, future))
        
        if len(self.pending_requests) >= self.batch_size:
            await self._process_batch()
        else:
            # Schedule batch processing
            asyncio.create_task(self._schedule_batch())
        
        return await future
    
    async def _schedule_batch(self):
        """Process batch after wait time."""
        await asyncio.sleep(self.wait_time)
        if self.pending_requests:
            await self._process_batch()
    
    async def _process_batch(self):
        """Process all pending requests."""
        batch = self.pending_requests[:self.batch_size]
        self.pending_requests = self.pending_requests[self.batch_size:]
        
        # Execute all coroutines concurrently
        tasks = [coro for _, coro, _ in batch]
        results = await asyncio.gather(*tasks, return_exceptions=True)
        
        # Set results
        for i, (key, _, future) in enumerate(batch):
            if isinstance(results[i], Exception):
                future.set_exception(results[i])
            else:
                future.set_result(results[i])
```

### Why Extend FastAPI Template
- Production-ready authentication and user management
- Established project structure and best practices
- Built-in testing and development tools
- Easy to add domain-specific features
- Active maintenance and community

### Why TimescaleDB
- PostgreSQL compatibility (works with SQLAlchemy)
- Optimized for time-series financial data
- Automatic data partitioning
- Continuous aggregates for different timeframes
- Compression for historical data

### Why Celery + RabbitMQ
- Reliable background task processing
- Built-in retry mechanisms
- Task prioritization and routing
- Scheduled tasks with Celery Beat
- Monitoring with Flower

### Why Redis
- Sub-millisecond caching
- Rate limiting implementation
- Session management
- WebSocket pub/sub
- Temporary data storage

### Why Discord Bot First
- Immediate user feedback channel
- Lower development overhead than full UI
- Built-in community and virality
- Proven monetization model
- Natural language interface
