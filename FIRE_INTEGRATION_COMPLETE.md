## 🎮 Usage Examples

### Basic Usage
```bash
# Load environment and execute task
source ./load_env.sh && ./fire "build FastAPI trading API"

# Quick status check
./fire --status

# Interactive mode
./fire --interactive

# Health check
./fire --health-check
```

### Advanced Usage with Aliases
```bash
# Source aliases for convenience
source ./fire-alias.sh

# Quick API development

# Machine learning pipeline

# React dashboard

# Django application

```
