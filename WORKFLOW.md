# Standard Development Workflow

## Process Overview
This workflow ensures structured, manageable development with clear planning and incremental progress.

## Standard Workflow Steps

1. **First think through the problem, read the codebase for relevant files, and write a plan to projectplan.md.**
   - Analyze the requirements thoroughly
   - Identify all relevant files and dependencies
   - Create a comprehensive plan document

2. **The plan should have a list of todo items that you can check off as you complete them**
   - Break down work into specific, actionable tasks
   - Use clear, measurable completion criteria
   - Organize tasks in logical order

3. **Before you begin working, check in with me and I will verify the plan.**
   - Present the plan for review and approval
   - Address any concerns or modifications
   - Ensure alignment on approach and scope

4. **Then, begin working on the todo items, marking them as complete as you go.**
   - Work through tasks systematically
   - Update progress in real-time
   - Mark tasks as completed immediately upon finishing

5. **Please every step of the way just give me a high level explanation of what changes you made**
   - Provide concise summaries of modifications
   - Focus on what changed, not detailed implementation
   - Keep explanations accessible and clear

6. **Make every task and code change you do as simple as possible. We want to avoid making any massive or complex changes. Every change should impact as little code as possible. Everything is about simplicity.**
   - Prioritize minimal, focused changes
   - Avoid over-engineering or complex solutions
   - Keep scope limited and impact contained
   - Choose the simplest approach that solves the problem

7. **Finally, add a review section to the projectplan.md file with a summary of the changes you made and any other relevant information.**
   - Document what was actually accomplished
   - Note any deviations from the original plan
   - Include lessons learned or important observations
   - Provide context for future reference

## Benefits of This Workflow

- **Predictable Process**: Consistent approach to all development work
- **Risk Mitigation**: Planning and approval reduces unexpected issues
- **Incremental Progress**: Small changes are easier to test and debug
- **Clear Communication**: Regular updates keep everyone aligned
- **Documentation**: Comprehensive record of decisions and changes
- **Simplicity Focus**: Prevents over-complex solutions
