## 🔧 Setup Instructions

### Step 1: Get Polygon.io API Key (Free)

1. **Sign up** at https://polygon.io/
2. **Choose free tier** (5 API calls/minute)
3. **Get your API key** from the dashboard
4. **Add to .env file**:

```bash
# Add this line to your .env file
POLYGON_API_KEY=your_polygon_api_key_here
```

### Step 2: Verify InfluxDB is Running

Your LDES system should already have InfluxDB running. Verify:

```bash
# Check if InfluxDB is accessible
curl -s http://localhost:8086/health
```

### Step 3: Start the Aggressive Backfill

```bash
# Execute the aggressive backfill
python start_aggressive_backfill.py
```
